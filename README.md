# Paul Mwa Guma Portfolio

A polished, Apple-inspired personal portfolio and CV website built with React, Vite, Tailwind CSS, Framer Motion and React Icons.

## Features

- Sticky, glassy navigation with smooth anchor scrolling
- Full-screen hero section with product-style launch presentation
- Scroll-reveal sections for about, projects, skills, education and contact
- Responsive cards, pill-based skill tags and Apple-like spacing
- CV download link via public/cv.pdf

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```
3. Build for production:
   ```bash
   npm run build
   ```

## Deployment

This project is ready for Vercel. The included vercel.json file ensures client-side routing works correctly.
